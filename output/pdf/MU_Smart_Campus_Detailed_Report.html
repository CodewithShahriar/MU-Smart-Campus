1. Executive Summary

MU Smart Campus is an integrated, responsive web application designed for Metropolitan University, Sylhet. It provides real-time schedule exploration, classroom vacancy discovery, campus space utilization analytics, and academic course offer management.

The system serves two distinct user personas: Students, who enjoy an unauthenticated, zero-friction discovery portal for finding classes and free rooms; and Faculty/Administrators, who gain access to an authenticated workspace capable of inline schedule modifications, clash-aware classroom reservations, and batch course-offer management.

Current Architecture Highlight: The platform operates as a high-performance client-side application built with React 19, TanStack Start/Router, and Zustand. Institutional data is ingested from standardized CSV repositories and augmented through local browser state persistence (musy-portal).

2. Background & Problem Statement

In contemporary academic institutions like Metropolitan University, timetable coordination and classroom allocation frequently encounter friction:

  • Static PDF Schedules: Traditional routines are circulated as massive static PDF tables or printed notice boards, making it cumbersome for students to search by section, batch, faculty initials, or room number.
  • Room Availability Uncertainty: Students seeking empty rooms for group study, club meetings, or makeup classes have to physically wander corridors to locate unoccupied rooms.
  • Faculty Scheduling Conflicts: Faculty members needing extra classes, makeup sessions, or examinations lack an instant feedback mechanism to detect room or faculty double-bookings.
  • Scattered Course Offer Data: Departmental course offerings and semester registrations are often published across disparate spreadsheets, lacking a centralized filtering interface.

3. System Purpose & Objectives

  • Centralized Schedule Indexing: Ingest 800+ schedule records and render them instantly searchable across 7+ dimensions (Day, Department, Batch, Section, Faculty, Course, Room, Slot).
  • Instant Classroom Availability Engine: Compute real-time vacancy for 33 campus rooms across six 90-minute daily instructional periods.
  • Interactive Faculty Reservation Workflow: Empower faculty to reserve free classrooms with real-time collision detection.
  • Spatial Utilization Analytics: Provide data visualizations showing peak load hours, high-occupancy days, and room utilization distributions.
  • Zero-Database Lightweight Deployment: Enable immediate academic demonstration and operation via static CSV pipelines with no heavy database server dependencies required for initial adoption.

5. Functional Scope & Modules

5.1 Student Portal

  • Student Dashboard (/student): Displays today's active classes, current live time slot, key metrics (total classes, rooms, courses, departments), and quick navigational shortcuts.
  • Routine Explorer (/student/routine): Comprehensive multi-filter interface with instant search for batch, section, faculty, room, and course code.
  • Classroom Vacancy Matrix (/student/rooms): Interactive grid showing real-time status (Available, Occupied, Booked) for any selected day and time slot.
  • Campus Analytics (/student/analytics): Charts detailing busy hours, department workloads, and room utilization trends powered by Recharts.
  • Course Offer Browser (/student/course-offer): Searchable catalog of departmental course offerings.

5.2 Faculty Portal

  • Authentication Guard (/faculty/login): Controlled demo login gateway with persistent credential validation.
  • Faculty Dashboard (/faculty): Quick summary of faculty teaching load, upcoming classes, and quick reservation shortcuts.
  • Routine Management Console (/faculty/manage): Inline schedule editor with built-in conflict detection indicators for room and faculty overlaps.
  • Classroom Reservation Engine (/faculty/book): Intelligent room booking form that automatically filters out occupied rooms for the selected time slot.
  • Course Offer Management (/faculty/course-offer): Administrative tooling for adding, editing, deleting, and CSV importing course offer entries.

9. Core Algorithms & Logic

9.1 Room Availability Derivation

To determine if room $R$ is vacant on day $D$ during slot $T$:

function getRoomStatus(room, day, time, routineEntries, bookings) {
  // 1. Check dynamic faculty reservations first
  const activeBooking = bookings.find(b => b.room === room && b.day === day && b.time === time);
  if (activeBooking) return { status: 'booked', details: activeBooking };

  // 2. Check scheduled curriculum routine
  const routineClass = routineEntries.find(c => c.room === room && c.day === day && c.time === time);
  if (routineClass) return { status: 'occupied', details: routineClass };

  // 3. Room is completely free
  return { status: 'available', details: null };
}

9.2 Real-Time Conflict Detection Engine

When a faculty member edits or creates a routine entry, the system evaluates two simultaneous collision vectors:

  • Room Double-Booking: Another class or booking is already scheduled in the same room on the same day and time slot.
  • Faculty Collision: The designated faculty instructor is already assigned to another lecture elsewhere during the identical time window.

The system renders real-time non-blocking warning banners with full context regarding the conflicting class to ensure academic flexibility while maintaining clarity.

11. Security & Technical Limitations

Important Operational Disclosures:
  1. Client-Side Authentication: Faculty authentication currently uses a client-evaluated credential check (admin@gmail.com / 123456). This is suitable for demonstration purposes but requires integration with institutional OAuth/SSO for enterprise deployment.
  2. Local Persistence Boundary: Modifications, reservations, and edits are stored in the user's browser local storage (musy-portal). Changes are not automatically synchronized across separate client machines.
  3. Non-Enforced Conflict Validation: Collision warnings notify users but do not strictly abort saves, permitting intentional co-scheduling or seminar bookings.
